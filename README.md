# Дашборд рекламы Форсайт

Клиентская версия: читает рабочую Google-таблицу напрямую и показывает динамику рекламы -
план и факт по договорам, воронку, сравнение год к году, разбор по каналам.

Вход по паролю. Данные не хранятся: при каждом обращении дашборд читает таблицу заново,
кэш - 30 минут.

## Это копия для деплоя

Рабочая версия и вся аналитика живут в основном репозитории проекта Форсайт
(`projects/forsite`, папка `dashboard/`). Здесь - **только код**, без бизнес-документов:
этот репозиторий уезжает на GitHub, а внутренние материалы остаются дома.

**После правок в основном репозитории** скопируй сюда заново:

```
forsite/dashboard/app_client.py  ->  app.py
forsite/dashboard/charts.py      ->  charts.py
forsite/dashboard/loader.py      ->  loader.py
forsite/dashboard/auth.py        ->  auth.py
```

Внутренняя версия (`app.py` из основного репозитория) сюда **не копируется** - в ней
пометки о дефектах данных, клиенту их видеть не нужно.

## Файлы

| Файл | Что делает |
|---|---|
| `app.py` | сам дашборд: сводка, KPI, год к году, недели, план/факт, воронка, каналы, стоимость договора |
| `charts.py` | построение всех блоков |
| `loader.py` | загрузка и нормализация данных из таблицы |
| `auth.py` | вход по паролю |

## Локальный запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Пароль для локального запуска - в `.streamlit/secrets.toml` (файл в git не попадает):

```toml
app_password = "пароль"
sheet_id = "идентификатор таблицы"
```

`sheet_id` можно не задавать - в коде есть запасное значение.

## Деплой на Streamlit Community Cloud

1. share.streamlit.io → **New app** → выбрать этот репозиторий, ветку и main file `app.py`.
2. **Advanced settings → Secrets** - вписать теми же двумя строками:

   ```toml
   app_password = "пароль"
   sheet_id = "идентификатор таблицы"
   ```

3. Deploy.

Секреты можно менять и после запуска: Settings → Secrets. Приложение перезапустится само.

## Важное

- **Репозиторий держать приватным.** Пароля и ID таблицы в коде нет, но публиковать код,
  работающий с данными клиента, незачем.
- Если пароль не задан, дашборд работает и показывает предупреждение, что открыт всем -
  чтобы забытая настройка не осталась незамеченной.
- Дашборд только читает таблицу. Записи нет: для неё нужен сервисный аккаунт Google.
